# NetScope — مكتبة الصور

يقرأ تطبيق NetScope (3.2.2 فما فوق) هذا المستودع عند كل فتح، فينزّل الصور الجديدة أو المتغيّرة فقط ويحفظها على الهاتف.

## الترتيب

```
devices/<اسم الموديل>.png|jpg|webp
types/<النوع>.png
```

### devices/
صورة لموديل محدد، مثل:
- `devices/LiteBeam 5AC Gen2.png`
- `devices/CCR2004-16G-2S+.png`

المطابقة تتجاهل الحروف الكبيرة والمسافات والرموز، والاسم الأقصر يطابق كل الموديلات التي تبدأ به
(مثلاً `CCR2004.png` تطابق `CCR2004-16G-2S+` و `CCR2004-1G-12S+2XS`).
### types/
صورة احتياطية حسب نوع الجهاز، تُستعمل عند عدم وجود صورة للموديل:

`mikrotik, airmax, ac, mtlink, lhg60, afx, af60, aclink, amlink, c5c, c5x, b11, b24, b5x, b5c, b5, switch`

## ملاحظات
- يصغّر التطبيق الصورة لعرض 320 بكسل، فلا داعي لصور أكبر من ~640 بكسل.
- يُفضَّل PNG بخلفية شفافة.
- لتحديث صورة يكفي استبدال الملف بنفس الاسم.
